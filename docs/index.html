Command Center

Explore Built-in Slash Commands

Click the copy button on any command to copy it directly to your clipboard.

/leetcode connect

Connects your Discord account to your LeetCode username and gives you a temporary bio verification token.

username: string
/leetcode verify

Verifies that the generated security token is present in your public LeetCode profile bio and completes linking.

no arguments
/challenge automate

Configures automated recurring challenge drops in a specific channel at a chosen daily time (HH:mm) with optional role ping.

time: HH:mm channel: #channel role: @role (optional)
/challenge stop-auto

Stops automated daily challenge drops for the current Discord server.

no arguments
/challenge create

Manually creates a new coding challenge for the server with a target number of problems to solve.

name: string target: integer
/challenge join

Joins an active server challenge so your progress is tracked automatically.

challenge_id: int (optional)
/challenge today

Displays today's active LeetCode challenge embed, question description, tags, and problem link.

no arguments
/challenge status

Shows paginated participant progress, completion status, and active participants for the challenge.

challenge_id: int (optional)
/challenge check

Manually triggers an immediate solution check for participants without waiting for the 5-minute cron poll.

no arguments
/challenge leaderboard

Displays the server leaderboard ranking users by completed challenges, streaks, and solve rate.

no arguments
