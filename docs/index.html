// CLI REFERENCE

Slash Commands

Click the copy button on any command to copy its syntax directly.

/leetcode connect

Binds your Discord handle to your LeetCode username and provides a temporary verification token.

username: string
/leetcode verify

Verifies that the generated token is present in your public LeetCode profile bio and finalizes connection.

no arguments
/challenge automate

Schedules recurring daily challenge drops in a specific channel at a chosen hour (HH:mm) with optional role ping.

time: HH:mm channel: #channel role: @role (optional)
/challenge stop-auto

Deactivates automated daily challenge drops for the current server.

no arguments
/challenge create

Manually creates a new coding challenge for the server with a target number of problems.

name: string target: integer
/challenge join

Enrolls your linked LeetCode handle into the active server challenge.

challenge_id: int (optional)
/challenge today

Displays today's active LeetCode question, difficulty, description snippet, tags, and problem link.

no arguments
/challenge status

Shows paginated participant progress, completion status, and active participants for the challenge.

challenge_id: int (optional)
/challenge check

Triggers an immediate verification check for participants without waiting for the 5-minute background cron.

no arguments
/challenge leaderboard

Displays the server leaderboard ranking users by completed challenges, streaks, and solve rate.

no arguments
